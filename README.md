# Ekmark

Ekmark adds text watermarks to your images. Use the online tool at
[ekmark.ekolix.com.ng](https://ekmark.ekolix.com.ng), or use the API from your
own application with the instructions in the
[API documentation](https://ekmark.ekolix.com.ng/documentation).

## Watermark images

1. Open the [watermark tool](https://ekmark.ekolix.com.ng/watermark).
2. Select or drag in up to 10 JPEG, PNG, or WebP images. Each image must be
   2 MiB or smaller.
3. Enter the watermark text (up to 60 characters), choose a font size from
   12–120 px, and select where the watermark should appear.
4. Process the images, then download them individually or use **Download All**.

The tool returns watermarked PNG files. Font sizing adjusts to the image
dimensions so the watermark fits.
